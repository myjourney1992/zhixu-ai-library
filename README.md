# 知序 · AI 学习资料库

一个中文 AI 学习资料库，汇总学习课程、开发实践、Agent、产业报告、视频和播客。使用原生 HTML、CSS、JavaScript，不依赖构建工具或后端。

在线网站：https://xingyu-ai-library.jocundcreek3.chatgpt.site

## 功能

- 23 份预置学习资料，分类、关键词搜索、难度筛选与排序。
- 4 条学习路径，8 个资讯入口。
- 点击卡片主体查看导读、思考问题和笔记；原文链接、收藏与完成状态独立操作。
- 支持添加个人资料、保存笔记、记录学习进度。
- 支持 JSON 导出、导入，以及旧版「AI 观察手册」备份导入。
- 适配手机和桌面浏览器，提供键盘操作与可访问标签。

## 本地运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080 。

## 文件结构

```text
index.html  页面结构
style.css   样式与响应式布局
app.js      资源数据、筛选、学习记录与交互
README.md   项目说明
```

## 维护与部署

在 `app.js` 的 `DATA`、`PATHS` 和 `CHANNELS` 中维护资料、学习路径和资讯入口。中文导读是阅读建议，资料内容、费用与可用性以来源平台为准。

把项目文件部署到支持静态文件的托管平台即可；无安装或构建步骤。本仓库用于保存和维护源码，推送 GitHub 不会自动更新现有 Sites 网站。

## 数据说明

学习记录保存在当前浏览器的 localStorage，键名为 `zhixu-ai-library-v1`。记录不会随账号、设备或网站域名自动同步；换浏览器、清理网站数据或更换部署域名前，请导出备份。

添加的个人资料也只保存在当前浏览器。若要让所有访客看到新的预置资料，需要修改源码后重新部署。
